# Array submission package

The current manuscript contains 28 visually checked pages, a 219-word abstract, twelve figures, eleven tables, twenty-five references and ten preserved native equations. Figure 12 and Table 11 report a separately frozen Cooja comparison; the abstract and conclusion now state its failure boundary explicitly.

## Scientific outcome

The original 750-run benchmark reports a conditional 4.67 percentage-point blackhole delivery gain for censored feedback, without a unique censoring or attention advantage. The new 600-run four-node Cooja study tests a relay that becomes a blackhole after warm-up. With scheduled delays, active proofs deliver 79.11%, censored feedback 32.94%, naive feedback 54.89% and censored feedback with proof generation 32.83%. This failure is retained rather than presented as a universally successful replacement. Existing 180-run and 240-run studies and their statistical families remain separate.
